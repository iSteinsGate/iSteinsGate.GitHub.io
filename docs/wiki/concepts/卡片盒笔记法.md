# 卡片盒笔记法

## 概述
Zettelkasten（卡片盒笔记法）是德国社会学家卢曼使用的知识管理方法。
## 五种笔记类型
1. **闪念笔记** — 快速捕捉想法
2. **文献笔记** — 阅读时的摘录和思考
3. **永久笔记** — 经过思考的原子化知识
4. **项目笔记** — 与特定项目相关
5. **索引笔记** — 入口和导航

## 核心原则
- 原子化：每条笔记只包含一个想法
- 双向链接：通过链接建立知识网络
- 自下而上：让结构自然涌现
