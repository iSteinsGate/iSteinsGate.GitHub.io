# DDD领域驱动设计

## 概述
DDD（Domain-Driven Design）是一种以领域为核心的软件设计方法论。
## 核心概念
- **Domain Primitive**: 领域原语，值对象
- **Entity**: 实体，有唯一标识
- **Aggregate**: 聚合，一致性边界
- **Repository**: 仓储，持久化抽象
- **Domain Service**: 领域服务

## 阿里DDD系列
1. Domain Primitive — 值对象设计
2. 应用架构 — 分层架构
3. Repository模式 — 持久化抽象
