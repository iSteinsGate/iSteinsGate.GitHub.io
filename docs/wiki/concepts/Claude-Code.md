# Claude Code

## 概述
Claude Code 是 Anthropic 的 AI 编程代理。在 LLM Wiki 模式中被推荐作为代理层（AI引擎）。

## 在 LLM Wiki 中的角色
- 作为**代理层**：执行所有知识处理任务
- 读取原始资料 → 提取信息 → 生成wiki页面 → 交叉引用
- 通过 Obsidian Skills 学习如何操作 Obsidian

## 为什么选择 Claude Code
1. **强大的文件操作** — 可以读写markdown文件
2. **工具调用** — 支持terminal、file等工具
3. **上下文理解** — 能理解复杂的文章内容
4. **Obsidian Skills支持** — 可以加载技能学习操作方式

## 替代方案
- **Hermes Agent** — 多平台AI代理
- **Cursor** — AI代码编辑器
- **VS Code + Claude扩展** — 编辑器集成
