# PARA方法

## 概述
PARA 是 Tiago Forte 提出的信息组织方法：Projects、Areas、Resources、Archives。
## 四个分类
1. **Projects** — 有明确目标和截止日期的短期项目
2. **Areas** — 需要长期维护的责任领域
3. **Resources** — 感兴趣的主题资料
4. **Archives** — 已完成/不再活跃的内容

## 在本Vault中的体现
```
00-Inbox/       → 收件箱（待分类）
01-Projects/    → 项目文档
02-Areas/       → 技术领域知识
03-Resources/   → 资料（空）
04-GTD/         → 日程管理
05-算法/        → 算法学习
```

## 与 LLM Wiki 的关系
PARA 是传统静态分类；[LLM-Wiki](LLM-Wiki.md) 是动态自动分类+交叉引用。
