# Andrej Karpathy

## 概述
Andrej Karpathy 是世界上最受尊敬的 AI 研究者之一。前 Tesla AI 总监，OpenAI 联合创始人之一。

## 核心贡献
- 提出 **LLM Wiki** 概念：用 LLM 构建和维护个人知识库
- 推文获得 19.6M 浏览、55.4K 点赞、6.58K 转发（2026年4月）
- 名言："Obsidian 是 IDE，LLM 是程序员，wiki 是代码库"

## LLM Wiki 理念
Karpathy 发现一个非常有用的模式：用 LLM 为各种研究兴趣主题构建个人知识库。他的 token 消耗从操作代码转向了操作知识。

## 关键观点
1. **范式转变**：不是人维护知识库问AI问题，而是AI构建和维护整个知识库
2. **复利效应**：每篇新资料让整个wiki更智能
3. **自动交叉引用**：一篇文章可能涉及10-15个wiki页面
