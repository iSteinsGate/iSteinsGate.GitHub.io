# SkyWalking

## 概述
Apache SkyWalking 是分布式系统的应用性能监控（APM）工具。
## 核心功能
- 分布式链路追踪
- 服务拓扑图
- 性能指标监控
- 告警

## 搭建步骤
1. 搭建 SkyWalking OAP Server
2. 搭建 SkyWalking UI
3. Java Agent 接入
4. 配置采样率和上报地址
