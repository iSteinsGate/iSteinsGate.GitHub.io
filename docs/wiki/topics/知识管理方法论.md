# 知识管理方法论

## 概述
知识管理是关于如何收集、组织、存储和检索知识的系统方法。AI 的出现正在改变这个领域。

## 传统方法

### Zettelkasten（卡片盒笔记法）
- **核心**: 原子化笔记 + 双向链接
- **优点**: 理论完美，促进深度思考
- **缺点**: 维护成本太高，大多数人坚持不下来

### PARA 方法
- **核心**: Projects / Areas / Resources / Archives
- **优点**: 结构清晰，适合项目管理
- **缺点**: 静态分类，缺乏动态连接

### 第二大脑（Second Brain）
- **核心**: 将所有知识外化存储
- **优点**: 减轻记忆负担
- **缺点**: 工具碎片化，知识孤立

## AI 驱动的方法

### [LLM-Wiki](LLM-Wiki.md)
- **核心**: AI构建和维护知识库
- **优点**: 自动化、复利效应、跨领域连接
- **实现**: [Obsidian](Obsidian.md) + [Claude-Code](Claude-Code.md) + [Obsidian-Skills](Obsidian-Skills.md)

### 关键转变
1. **从人维护到AI维护**
2. **从手动链接到自动交叉引用**
3. **从线性增长到指数复利**
4. **从单一领域到跨领域连接**

## 方法论对比

| 维度 | Zettelkasten | PARA | LLM Wiki |
|------|:----------:|:----:|:--------:|
| 维护成本 | 高 | 中 | 低（AI自动） |
| 连接方式 | 手动 | 手动 | 自动 |
| 知识增长 | 线性 | 线性 | 指数（复利） |
| 跨领域 | 难 | 难 | 自动 |
| 学习曲线 | 高 | 中 | 低 |
