# 医疗信息化项目

## 概述
医疗信息系统项目，包括传染病监测和医护对讲白板。
## 项目一：传染病监测系统
- **国家传染病监测实施** — 环境准备、部署流程
- **八一三医院** — 数据问题处理
- **眉县** — 上报问题处理
- **长生医院** — 实施记录
- **传染病要求** — 业务规则（诊断不能删除、实时触发等）

## 项目二：红原医护对讲白板
- **视图文档** — 8个版本迭代（V1.0→V1.7）
- **数据库视图设计** — v_yhdj_visit、v_yhdj_ward
- **业务需求** — 儿科/妇产科白板展示

## 项目三：其他
- **剩余量** — 药品剩余量计算逻辑
- **XXLJob清日志** — 定时任务日志清理
