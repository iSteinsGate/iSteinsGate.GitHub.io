### 第 46 题「全排列」

[leetcode-全排列](https://leetcode.cn/problems/permutations/)
- 解法
```java
class Solution {  
    List<List<Integer>> res = new LinkedList();  
    public List<List<Integer>> permute(int[] nums) {  
        Boolean[] used = new Boolean[nums.length];  
        backtrack(new LinkedList(),nums,used);  
        return res;  
    }  
    /**  
     * @target 路径  
     * @nums 选择列表  
     * @used 使用列表  
     */  
    public void backtrack(LinkedList<Integer> target,int[] nums, Boolean[] used){  
        // 路径与选择列表相等 结束  
        if(target.size() == nums.length){  
            res.add(new LinkedList(target));  
            return;        }  
        for(int i=0;i<nums.length;i++){  
            if(used[i]!= null && used[i] == true){  
                continue;  
            }  
            // 选择  
            used[i] = true;  
            target.addLast(nums[i]);  
            backtrack(target,nums,used);  
            // 撤销选择  
            used[i] = false;  
            target.removeLast();  
        }  
    }  
}
```


### 第 51 题「N皇后」
[leetcode-N皇后](https://leetcode.cn/problems/n-queens/)

- 解法一：使用数字替代皇后所在的位置
```java
public class Test {  
    List<List<String>> res = new LinkedList();  
    Map<Integer, String> keyMap = new HashMap();  
  
    public List<List<String>> solveNQueens(int n) {  
        initKey(n);  
        backtrack(new LinkedList(), 0, new boolean[n]);  
        // 0:Q在第一位，1:Q在第二位 2:Q在第三位 3:Q在第四位  
        // n = 4 最总答案：[[1,3,0,2],[2,0,3,1]] 即 对应 [[".Q..","...Q","Q...","..Q."],["..Q.","Q...","...Q",".Q.."]]        return res;  
    }  
  
    /**  
     * @param track 路径  
     * @param row   row后面的都是选择列表  
     * @param used  
     */  
    public void backtrack(LinkedList<Integer> track, int row, boolean[] used) {  
  
        // 数量相同  
        if (track.size() == used.length) {  
            // res.add(new LinkedList(track));  
            res.add(convert(track));  
  
            return;        }  
  
        for (int i = 0; i < used.length; i++) {  
            // 同一个列  
            if (used[i]) {  
                continue;  
            }  
            // 并且一同一斜线  
            if (isSameLine(track, row, i)) {  
                continue;  
            }  
            used[i] = true;  
            track.addLast(i);  
            backtrack(track, row + 1, used);  
            used[i] = false;  
            track.removeLast();  
        }  
    }  
  
    /**  
     * 初始化 keyMap,  key的值表示Q的位置即 0对应Q...  1对应.Q..  
     */    void initKey(int n) {  
        for (int i = 0; i < n; i++) {  
            StringBuilder a = new StringBuilder();  
  
            for (int j = 0; j < n; j++) {  
                if (j == i) {  
                    a.append("Q");  
                } else {  
                    a.append(".");  
                }  
            }  
            keyMap.put(i, a.toString());  
        }  
    }  
  
    /**  
     * 转换  
     * // 0标识Q在第一位：".Q.."，1标识Q在第二位：".Q.."  2标识Q在第三位："..Q." 3标识Q在第四位："...Q"  
     * // n = 4 最总答案：[[1,3,0,2],[2,0,3,1]] 即 对应 [[".Q..","...Q","Q...","..Q."],["..Q.","Q...","...Q",".Q.."]]  
     */    List<String> convert(LinkedList<Integer> track) {  
        List<String> result = new ArrayList();  
        for (int i = 0; i < track.size(); i++) {  
            int target = track.get(i);  
            result.add(keyMap.get(target));  
        }  
        return result;  
    }  
  
    /**  
     * 判断是否在同一斜线上  
     */  
    public boolean isSameLine(LinkedList<Integer> track, int row, int col) {  
        if (track.size() < 1) {  
            return false;  
        }  
        // 处于同一个斜线 , 注意5皇后 1,3,0,4,2 这种也不满足  1,4在同一个斜线上  
        for (int i = 0; i < track.size(); i++) {  
            if ((track.get(i) + (row - i) == col) || (track.get(i) - (row - i) == col)) {  
                return true;  
            }  
        }  
        return false;  
    }  
}
```

## 二叉树
###  第 104 题「二叉树的最大深度」
[leetcode-二叉树的最大深度](https://leetcode.cn/problems/maximum-depth-of-binary-tree/)
- 遍历解法
```java
class Solution {
    int maxDepth;
    public int maxDepth(TreeNode root) {
        if(root == null){
            return 0;
        }
        int leftDepth = maxDepth(root.left);
        int rightDepth = maxDepth(root.right);
        // 根据左右子树的最大深度推出原二叉树的最大深度
        // +1 加上跟节点自己
        maxDepth = Math.max(leftDepth,rightDepth) +1 ;
        return maxDepth;
    }
}
```

### 第 543 题「二叉树的直径」

[二叉树的直径](https://leetcode.cn/problems/diameter-of-binary-tree/)
- 暴力解法1

```java
class Solution {  
    // 外部变量 + 遍历  复杂度 O(N^2)
    public int diameterOfBinaryTree(TreeNode root) {  
        treaverseRoot(root);  
        return maxDiameter;  
    }  
    int maxDiameter = 0;  
    void treaverseRoot(TreeNode root) {  
        if (root == null) {  
            return;  
        }  
        int leftHeigh = maxDepth(root.left);  
        int rightHeigh = maxDepth(root.right);  
        // 最大直径
        int currentDiameter = leftHeigh + rightHeigh；
        maxDiameter = Math.max(maxDiameter, currentDiameter);  

        diameterOfBinaryTree(root.left);  
        diameterOfBinaryTree(root.right);  
    }  
    // 获取最大深度
    int maxDepth(TreeNode root) {  
        if (root == null) {  
            return 0;  
        }  
        int leftHeigh = maxDepth(root.left);  
        int rightHeigh = maxDepth(root.right);  
        return Math.max(leftHeigh, rightHeigh) + 1;  
    }  
}
```
