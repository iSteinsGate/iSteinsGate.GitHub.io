# 1 环境准备
```anyblock
[list2node]
- ## 环境准备
	- 1.传染病机构编码
	- 2.传染病机构名称
	- 3.前置机服务的ip端口
	- 4.传染病机构授权码
```

# 2 对码处理
```anyblock
[list2node]
- ## 对码处理
	- 1.科室对码（**HIS**部门菜单对应医保科别和科室类别）
	- 2.药品对码（**HIS**基本公卫应用/药品对码菜单）
	- 3.标本类型对码（**HIS**控制中心应用/系统字典对码）
	- 4.检验项目对码（**前置机软件**）
```
