



## 1. 准备工作

1. 在Cursor中打开本工作区

2. 确保所有目录结构已按规划创建

3. 准备好原始材料

  

## 2. 文件组织规范

  

### 数据库表结构文件

- 存放在 `raw_materials/01_database_schema/`

- 按业务模块分目录

- 每个SQL文件只包含一个模块的表

- 文件名应明确表示模块名称

  

### 字典数据文件

- 存放在 `raw_materials/02_dictionary_data/`

- 使用Markdown格式，清晰展示映射关系

- 按功能分类存储

  

### 业务需求文件

- 存放在 `business_requirements/01_view_requirements/`

- 按业务模块分目录

- 每个视图一个独立的Markdown文件

- 文件命名：`v_视图名称.md`

  

### 提示词模板

- 存放在 `prompt_templates/`

- 按功能分类存储

- 使用编号便于查找

  

### 生成的SQL文件

- 存放在 `generated_sql/01_views/`

- 按业务模块分目录

- 文件名包含数据库版本标识：`_pg11`

  

## 3. 使用流程

  

### 步骤1：分析阶段

使用分析工具模板了解表结构和需求

  

### 步骤2：映射阶段

使用字段映射模板分析字段对应关系

  

### 步骤3：生成阶段

使用SQL生成模板创建视图SQL

  

### 步骤4：验证阶段

使用验证工具检查SQL质量和性能

  

### 步骤5：文档阶段

生成相关文档和测试用例

  

## 4. 常用命令

- 查看表结构：打开对应SQL文件

- 分析字段映射：使用字段映射器模板

- 生成视图SQL：使用视图生成器模板

- 验证SQL语法：使用SQL验证器模板
