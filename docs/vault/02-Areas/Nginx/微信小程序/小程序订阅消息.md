
#小程序  #消息


## 1. 订阅消息（前端）
[小程序订阅](https://developers.weixin.qq.com/miniprogram/dev/api/open-api/subscribe-message/wx.requestSubscribeMessage.html)
小程序登录返回订阅的消息模板id

>[!note]
>每次只能订阅三个模板
## 2.授权
[获取接口凭证](https://developers.weixin.qq.com/miniprogram/dev/OpenApiDoc/mp-access-token/getAccessToken.html)


## 3.发送消息

[发送消息文档](https://developers.weixin.qq.com/miniprogram/dev/OpenApiDoc/mp-message-management/subscribe-message/sendMessage.html)

```
POST https://api.weixin.qq.com/cgi-bin/message/subscribe/send?access_token=ACCESS_TOKEN 
```
